测试身份

Alice 是本机测试身份，不是正式账号。令牌仅用于本次演示页面。

场景包与合成评测

内置包固定 mock Harness 与 ticket.get；导入拒绝写工具、外部地址及未知字段。成功与接口失败两条样例由实际临时Run事件检查；结果仅代表合成链路，不替代真实模型质量或发布评测。

体验步骤

  1. 配置页先“载入内置工单场景包”→“校验场景包”→预览并“确认填入草稿配置”（均不保存）。再填写独立 Agent ID，版本填 1、Harness 使用 mock，完整 config 填 {"tools":["ticket.get"]}，保存草稿。
  2. 选择“评测与发布”，显式确认开发态评测，再确认发布；只写入本次临时库。
  3. 工作台应用 Alice 测试令牌，填写 Agent ID；消息输入 SYNTHETIC_TICKET_SUMMARY，登记并确认执行一次，随后由本人确认收口。记录 Run ID。
  4. 读取同一 Run，应看到“模拟工单摘要：SYNTHETIC-1 / 设备无法连接 / open”。结果卡分开显示 Run 状态、工具结果与助手文本；使用工作台链接进入同 Run 轨迹页，重新应用 Alice 后显式读取。Portal 则使用工作台中的“查看此 Run 只读轨迹”。

仅调用合成只读工具 ticket.get；模拟内容不代表真实自然语言效果或业务数据。未知结果先只读对账，不自动重发。

按 Ctrl+C 停止；服务最长约 30 分钟，只监听本机回环地址。

销售助理只读 · 合成场景包

在管理 Agent 页面选择“载入内置销售场景包”，校验后显式填入草稿，使用独立 Agent ID。保存、开发态评测确认与发布沿用现有闸门。

工作台应用 Alice 测试身份，输入 SYNTHETIC_SALES_SUMMARY，依次登记、执行一次与本人确认收口。仅返回本人商机；事实与建议附商机 ID 和更新时间，缺失金额／日期显示未知，不跨币种合计。

SYNTHETIC_SALES_EMPTY 验证空筛选；SYNTHETIC_SALES_FAILURE 验证工具故障不生成成功摘要。均使用 synthetic-sales 模拟模型与合成工具，非真实CRM、模型质量或投产验收。

经营分析 · 合成订单

使用 --analytics-readonly 隔离启动模式。在管理Agent载入内置经营场景包，校验后显式保存并开发评测发布。工作台应用Alice测试身份，发送 SYNTHETIC_ORDER_SUMMARY，完成登记、执行一次和本人ACK。

指标卡只展示工具聚合：创建窗口、读取时状态、分币种金额（分）及覆盖率，不代表财务收入。SYNTHETIC_ORDER_INCOMPLETE 展示缺失金额；SYNTHETIC_ORDER_EMPTY 展示空窗口。Bob无数据权限；管理员也不得读他人分析Run。不会调用真实模型或数据，北极星未定义。
