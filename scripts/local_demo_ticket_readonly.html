体验步骤

  1. 配置页新建 Agent，版本填 1、Harness 使用 mock，完整 config 填 {"tools":["ticket.get"]}，保存草稿。
  2. 选择“评测与发布”，显式确认开发态评测，再确认发布；只写入本次临时库。
  3. 工作台应用 Alice 测试令牌，填写 Agent ID；消息输入 SYNTHETIC_TICKET_SUMMARY，登记并确认执行一次，随后由本人确认收口。记录 Run ID。
  4. 读取同一 Run，应看到“模拟工单摘要：设备无法连接，已建议检查网络。”在轨迹页应用 Alice，输入 Run ID，读取只读事件。
