## 本轮最小闭环与安全契约

### S12.1 响应范围一致性

运营 Trace 结果除了原有租户、Agent、scope 与完整扫描检查，必须与请求的 since／until 时间点严格一致；等价时区表示可接受，错误日期或无效日期失败关闭、清空旧统计。没有新建指标、改变后端计费或把缺失值补零。

### S12.3 只取消读取，不取消 Run

SDK `inspect(runId, signal?)` 的可选 AbortSignal 仅传给两个 GET。身份头等待前后、fetch 后、正文解析后都检查取消，即使替身或传输忽略 abort，也不能继续请求 events 或返回旧结果。写方法不接受这个取消参数，不自动重试。

工作台新增“停止本次只读刷新”：中止当前读、推进读取代次并清空本次视图，允许重新应用身份和手动定位；不会调用 Run 取消接口、撤销已受理 POST 或解除未知写结果锁。创建／审批／输入 POST 迟到时若组件已卸载，不再用已清空身份发起后续 GET。已有 generation 隔离继续阻止旧响应覆盖新身份。

元数据必须先匹配请求 Run ID，之后才能读取 events；事件必须属于同 Run，seq 为正安全整数且严格递增（允许合法缺号），type 为字符串，payload 为非 null 非数组对象。畸形事件拒绝展示卡片，不以跳过坏数据伪造完整历史。
