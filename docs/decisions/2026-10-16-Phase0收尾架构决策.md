## 2. 接口约定

| 编号 | 决策 | 落点 |
|---|---|---|
| D8 | 业务规则拒绝统一返回 HTTP 409（发布闸门、Skill 供应链规则、审批状态或参数指纹不符），422 只保留给 FastAPI 参数校验；路由用 `responses={409: {"model": ErrorDetail}}` 声明 | runtime `api/admin.py`、`api/messages.py`；gateway `main.py`；console-api `main.py` |
| D9 | 不存在的 Run 统一 404（`RunNotFound` 异常处理器）；`since_seq` 约束 `0 ≤ x ≤ 2^53` | runtime `main.py`、`state/eventlog.py` |
| D10 | Run API 响应挂 `response_model`（RunView / RunStateView / RunEventsView / ApprovalView）；events 使用 `RunEventView(RunEvent)` 避免与契约 `RunEvent` 在 OpenAPI 合并时同名异构；`resume` 为 SSE 不挂模型，事件 schema 由 `x-sse-event-schema` 指明 | runtime `api/views.py`、`scripts/export_openapi.py` |
| D11 | SDK 的 `approve` 必须回传 `params_hash`（Python 与 Web SDK 均已改） | `packages/sdk-python`、`packages/sdk-web` |
