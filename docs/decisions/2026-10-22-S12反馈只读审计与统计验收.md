# S12.1 单租户反馈只读审计与统计

日期：2026-10-22。范围：用户批准的本轮本机实现与隔离回归。自动跟进保持 PAUSED；未部署生产、操作真实业务、变更账号、增加数据库迁移或反馈写入口。

## 1. 已实现的最小闭环

- Runtime `GET /v1/metrics/feedback-cohort`：仅真实验签用户 JWT、既有 platform-admin，限定 JWT 租户；拒绝开发头／服务身份，prod 禁用。带时区创建 cohort `[since,until)` 最长七天、最多 2000 个 Run，一次 SQL 返回完成／失败／取消／未决和有限事实。
- 本机真实 Run 暴露既有 `finished_at` 未填充的问题。只读查询在同一次 SQL 中读取 `seq <= last_seq` 的唯一 completed 状态事件作为完成时间证据，标注 `finished_at_source`；行／事件冲突、缺失时间仍拒绝。不改 Runtime 业务写链路，也不以读时钟补齐完成时间。
- Console `GET /metrics/feedback`：要求既有租户管理员权限，并将内存用户 Bearer 仅交 Runtime 验签核实范围，再检查 Console Agent。令牌租户不符拒绝；用户令牌不交 Langfuse，不复用发布服务账号。
- 本机 Langfuse v3 Scores v2／Trace GET：每页 100、最多 20 页，复用有界响应／超时、loopback、无代理／重定向。稳定 ID 完全副本去重，同 ID 内容冲突、分页变化／重复、超限或不兼容均受控不可用，不返回部分比率。先检查 Trace 归属再排除非 cohort，不能用评分自报 Run 隐藏属于本租户的记录；不展示其他租户数量。
- Operations 独立反馈区：展示实际验签身份、分母、二元分子、未知比率和排除诊断。身份、令牌草稿、Agent、时间窗变化清空并取消旧读取；代次检查阻断忽略 abort 的迟到响应。令牌只在内存，不写浏览器存储。
- 只返回范围、读取起止、状态计数及反馈诊断；不返回评论、correction、评分 ID、原发起人或个人排名。HTTP 下游统计请求只有 GET。

## 2. 固定统计与信任契约

E 是创建 cohort 中读取时已 completed 的唯一 Run，Runtime 归属与原发起人为核对依据。评分只处理 user_feedback，同 Run 多 Trace 最多一份最终评价；不同 score ID 不是写请求幂等证明。评分／Trace／Run 的租户、Agent、Run、主体必须一致；关联一致不等于来源可信。

内部计算器以可靠修订时间取最新，缺失时间或并列最新冲突，不按 ID 任选。最新精确 NUMERIC ±1 才参与二元统计；0、小数、布尔、非法值不回溯旧评分，终态前评分另列。满意度 P/(P+N)，有效二元反馈覆盖率 (P+N)/E；零分母为 null。存在影响完整性的未验证／冲突／非法来源时正式比率 null；完整无评分且 E>0 时观测覆盖率可为 0。

真实读取路径始终构造未验证评分，忽略 metadata.verified，不能通过 HTTP 或配置提升历史数据信任级别。可信正向计算仅由测试直接构造内部输入，不能宣称真实满意度已可用。读取无历史快照：`snapshot_guaranteed=false`，迟到反馈／状态可能改变结果。
