# 工单只读接口与模型非生产接入契约草案

日期：2026-10-27。状态：离线建议，未经业务、数据、安全及费用负责人确认，不能直接启用。依据现有合成适配器与前置清单梳理，未读取凭据、连接真实服务或访问数据库。

## 工单接口：建议最小契约

首批建议只开放 `ticket.get`，由用户指定工单 ID；`ticket.search` 暂缓，避免在逐行权限和结果可见性尚不明确时扩大范围。仅允许只读方法，工具目录及策略同时限制写工具；提示词不构成权限控制。实际 URI、版本、字段类型和语义均须工单系统负责人提供文档并确认，不能把替身路径视为真实 API。

| 字段 | 当前合成模型 | 建议首批 | 待业务确认 |
|---|---|---|---|
| `id`、`tenant` | 字符串；get 核对请求 ID 和租户 | ID 用于精确定位，tenant 仅用于可信范围核验 | ID 命名空间、租户可信来源及跨租户一致性 |
| `title`、`status` | 字符串 | 摘要候选字段 | 状态字典、字段分类及缺失处理 |
| `description` | 字符串 | 仅在数据责任人批准后送模型 | 个人信息／敏感信息、脱敏与最大长度 |
| `created_at`、`updated_at` | 字符串；替身未强制时区 | 候选时间字段 | 时间格式、时区、含义与必要性 |
| `priority`、`category` | 可空 | 默认不外发，按摘要需要审批 | 枚举、空值语义与敏感级别 |
| `owner`、`requester` | 字符串 | 默认不外发人员标识 | 是否必要、可否映射或脱敏 |
| `records`、`records_truncated` | 最多 50 条及截断标识 | 默认不外发；如需摘要须单独批准内容及上限 | 记录顺序、可见范围、截断语义和敏感字段 |
| `customer_feedback`、`closed_at` | 可空；反馈结构未固定 | 默认不外发 | 是否必要、结构和可见性 |

合成适配器现已在 get 校验完整 Ticket 后仅投影 id、title、status；这只是替身路径，真实接入仍须实现并验证独立的输出投影。标题本身也可能包含敏感信息。附件、评论、处理记录与反馈不隐含授权。对于 search，须另外确认过滤项、稳定分页／并发修改语义、每行授权、总数和游标是否泄露，以及是否允许跨页变化；未确认前不启用真实 search。

### 身份委托与行权限

1. 推荐经现有网关验签、策略判定并绑定用户与租户后，采用工单系统认可的用户委托或受限令牌交换；下游令牌的 issuer、audience、subject、租户映射、scope、有效期、撤权、重放和责任方需由双方确认。不能以调用方传入的 tenant 或共享全权账号替代真实主体。用户 token 不得记录、透传到模型或放入文档。
2. 工单系统是行权限权威：每次 get 按委托主体和可信租户检查目标工单；只验证返回租户不等于行权限。未来若开放 search，每条结果与总数、游标均须遵守相同可见性，不足以通过客户端过滤补救。
3. 无权与不存在建议对客户端统一结果；身份无效、映射冲突、策略或下游不可用均失败关闭，禁止回退到高权限身份。只读仍可能产生下游审计或计费，须事先确认。
4. 现有合成适配器仅检查注入身份的 `act_verified` 等属性，不自行验签；签名测试路由通过测试注入接桥，默认 MCP 路由尚未连接真实 HTTP。工单链路已有 act 防重放要求与其他数据链路规则不能混用，多副本防重放存储需另行核实。

## 真实模型：非生产门禁

| 项目 | 推荐方案 | 当前状态／负责人需确认 |
|---|---|---|
| 供应商和模型 | 先选一个获批非生产端点、固定版本或受控别名；确认工具调用能力、地区及数据留存／训练条款 | **未选定**；仓库别名仅是示例，未证明供应商已获批或可用 |
| 凭据 | 专用非生产身份，受控密钥管理引用；最小权限、有效期和撤销责任明确 | 安全引用及负责人未知；不在聊天或报告提供密钥内容，不读取生产密钥 |
| 网络出口 | 指定 HTTPS 主机、端口、TLS 信任与 DNS／代理，禁止未批准重定向、回退和附加回调；验证实际所有出站通道 | 目标和网络所有者授权未知；模型网关示例可能包含其他模型和观测回调，不能整份照搬 |
| 数据 | 先只发合成工单；真实工单进入模型需单独批准数据分级、字段、脱敏、地域及用途 | 当前无真实数据外发授权 |
| 预算 | 确认费用归属、最大金额／调用数、单次 token、执行时窗、停止条件及预算执行者 | 数值未知；不能将应用侧计数当供应商硬限额，需说明计费延迟与超额风险 |
| 审计和观测 | 先本地最小审计，不含令牌与原文；任何外部 Trace、日志、留存单独批准 | 不写真实 Langfuse Trace；具体审计与留存责任待定 |

模型接入与工单接口接入是两项独立授权；两者结合并向模型发送真实工单是第三项数据使用／出站授权。请求格式、调用价格及数据政策须在供应商确定后核对其正式文档和组织协议，本轮未做此类核验。

## 可直接执行与待确认

**可直接执行（仍需遵循本轮以后的具体授权）**：基于纯替身细化字段投影和错误契约测试；构造同租户不同主体、跨租户、权限撤销、敏感字段剔除和分页泄露样例；离线检查网关配置的潜在出口并设计合成模型测试。上述为候选工作，本轮未实现或运行这些新增测试。

**必须人工确认后才能进入真实接入**：工单系统负责人提供非生产 API 文档与测试环境引用、允许字段／数据分类及只读副作用；IdP 和业务系统负责人确认身份委托与逐行权限、撤权及重放责任；模型／安全／费用负责人确认供应商版本、凭据安全引用、网络出口、数据处理和预算硬门禁；另确认具体非生产联调、测试数据及费用授权。不要在聊天发送凭据值。原库、真实账号和生产仍不在范围。

## 推荐顺序

先完成纯替身字段投影及授权失败用例，再分别申请“真实模型 + 合成工单”和“非生产工单接口 + 授权测试数据”的独立验证；只有两者均有证据且另行批准真实数据出站后才组合。北极星继续待定义。本轮为文档工作，未运行新增代码或测试，不能替代真实供应商、身份或行权限验收。
