# S12.4 发布与节点管理组件自动验收

## 范围与边界

承接《2026-10-21-S12组件与端到端自动验收》，本轮只补本机自动验证与测试发现的最小产品缺陷，不启用自动跟进、不部署生产、不执行真实业务写操作；未提交、建分支、推送、合并或修改现有外部服务。保留原有未提交变更，没有新增必须人工确认却绕过确认执行的事项。

所有新管理组件测试均挂载真实 Vue 页面，使用真实 DOM 事件、响应式状态、子组件与前端请求代码；Console 接口由 Playwright 路由替身完全截获，未配置请求返回 404，不透传真实控制面。新测试不是节点协议端到端或真实 Langfuse 评测验收。原有真实隔离 Console／Runtime 工作台 E2E 保留，继续只调用合成工具。

## 新增可验证闭环

### 发布页：5 项

1. 开发 flag 必须显式确认；预览及取消不写入、待确认时身份不能切换。最终提交精确绑定版本路径与参数，只发送一次；服务端 409 拒绝不展示发布成功、草稿仍为草稿。
2. 0% 预发布必须有白名单，主体去重保留顺序；确认时参数输入禁用，提交后重新读取服务端版本状态，不凭请求成功伪造状态。
3. Langfuse 模式缺少引用时本地拒绝；只读 GET 带编码后的引用，缺失统计展示“未知”而非零；修改引用清空旧结果，应用另一租户清空旧版本与发布面板，不产生写请求。
4. 已发布版本只能复制为新草稿，版本字段必须重新填写、扩展 config 原样保留；切为 USER 后保存与发布按钮禁用。
5. 灰度为指定版本的 PUT，回滚为指定版本的 POST；二者精确区分 body、确认与取消，回滚取消不请求服务端。

### 节点页：7 项

1. 创建分组 POST 与编辑说明 PUT 分离；编辑时组名只读，保存后刷新。
2. 默认组和非空组禁止删除；空组删除二次确认、取消不写；租户管理员不能增删改基础设施或调整成员。
3. 节点成员至少一组；新增／移除路由组立即显示／移除权重输入，绑定按当前租户和精确权重二次确认提交。
4. 修改参数使旧指令预览失效；确认只发一次 POST，202 只展示已入队；同 ID 的 pending→ok 只读刷新不重发；租户管理员禁用共享节点重启。
5. 下发网络结果未知后锁定写入，通过原租户／节点／操作者的审计候选查同 ID 回执；即便找到 ok，或手动刷新，也不解锁；切换租户清空旧回执且禁止跨租户定位原请求。
6. 历史下一页使用服务端递减游标；跨租户返回页失败关闭并清空旧历史，不触发节点拉取、ACK 或任何写请求。
7. switch_model 的五个 CAS／模型字段、reload_skills 的名称／版本／SHA256、graceful_restart 的 timeout_s，均只提交原契约参数。所有入队／回执为替身，不执行真实模型切换、下载 Skill 或重启。

## 测试发现及最小修复

新增路由绑定测试稳定复现：勾选组后 checkbox 为 checked，但权重输入数组为 `[]`，期望为 `["general 权重"]`。根因是 `hasWeight` 调用 `Object.prototype.hasOwnProperty.call`，未建立 Vue 对该响应式对象新增键的依赖；ref 本身未替换，新增键无法触发条件区域重渲染。

仅将 `hasWeight` 改为 `Object.keys(weights.value).includes(name)`，追踪对象键迭代，同时继续只接受自有键、兼容无原型权重对象。保留原严格断言并增加取消勾选后权重框消失的验证，未用额外点击、重新刷新、放宽阈值或删除断言绕过缺陷。

调试期间另修正测试定位器：select 的可访问名称包含选项文本，使用具名 combobox；角色变更测试等待该角色的实际只读刷新完成后再检查权限。核对本机 Playwright 源码发现，label 内 option 的 `isDisabled()` 会重定向到父 select，而非检查 option 本身；因此重启权限同时严格断言原生 `option.disabled === true` 和 `option.matches(':disabled') === true`，没有删除禁用要求或改变产品权限。定位 5 秒、状态轮询 10 秒、单项测试 30 秒上限不变。
