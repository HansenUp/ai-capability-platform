# S14.1 本机版本账本与重新授权验收（2026-10-27）

## 范围与实现

依据《2026-10-27-S14版本账本本机契约》，仅使用可销毁 SQLite、合成清单／策略及签名测试身份。新增本机实验账本和显式注入的 ReviewedQuery 提供者，不接真实数据、身份服务或策略服务，不开放生产接口。清单与策略按租户和视图分别递增；`BEGIN IMMEDIATE` 与期望版本实现原子发布，命令 ID 不可复用。撤权追加记录；重授权产生新版本，活动策略绑定当前清单版本和事件哈希。旧策略不自动继承新的清单授权。请求返回前的第二次校验发现版本变化时拒绝结果。

本轮写接口是受信测试调用者直接注入，尚无可信发布者认证、签名、真实审批或独立持久防回滚锚点；同权限者修改数据库或整体恢复旧备份不能由本机账本检测。正式采用前需确认独立单调锚点及恢复／故障处理方案、受控签名和审核身份、数据源租户标签真实性，以及真实 IdP／策略服务接入和权限；这些没有执行。T2 检查之后发生的撤权不能回溯撤销已准入响应，跨服务原子性未证明。S14.1 保持未完成；真实环境、生产安全与其他阶段门禁不因本机通过而解除。
