# Portal 我的任务中心验收

## 本轮交付

- 新增 /tasks，本机演示路由与正式 Portal OIDC 路由均接入；Agent 列表提供“我的任务”，工作台提供返回入口。
- 用户显式读取首页，先复用 SDK ledger() 核对签名身份及主体账本，再用 listMyRuns() 固定 subject 查询本人 Run；管理员同样显式绑定本人。支持 Agent 精确筛选、全部七种 Runtime 状态筛选、每页20条及下一页游标。
- 筛选变更清空旧页；分页重新核对身份，主体/租户/scope 改变则拒绝续页。错误清空、取消旧请求与代际检查，迟到响应不能恢复旧列表。令牌仅在单次读取闭包内，不写浏览器存储。
- 任务链接携带 Agent 与 Run ID 到原工作台。详情须显式应用身份、定位链接 Run 并只读读取；结果卡、审批、输入、回执、SSE与同Run轨迹复用已有实现，不自动执行/重发/ACK。
- 返回列表重新读取，不持久保存筛选/页数据；本轮未实现跨页面筛选记忆。不是审批收件箱，不查询他人待批任务。
- SDK 为新增只读方法；原 listOwnRuns 与 Python SDK 行为未改。B2报告10个文件SHA全部一致。
