## 可直接执行与已执行的最小补验

### S3 存储的离线真实缺口

原 `test_s3_store_roundtrip` 依赖真实 MinIO 且会建桶／写对象／清理，不自动启用。审查其未被默认测试覆盖的适配器路径，发现 S3Store 在 `_check(key)` 前访问客户端及创建桶：非法键可能产生外部副作用，即使最终拒绝键，也不是失败前零副作用。

新增纯内存客户端测试，所有 endpoint／凭据均为无实际意义的 synthetic，不创建真实 MinIO 客户端：非法 put／get 键不得访问客户端、建桶、写对象或置 ready；有效往返只初始化一次，正常及读取失败都关闭响应并释放连接。

初版替身未提供 put_object／get_object，红测先遇 AttributeError（`s3-red.log`），仅修正替身完整性后重跑，`s3-red-complete-client.log` 明确显示本应空的调用列表出现 client／exists／create 六次操作；这是实际产品红测，不用缺少替身方法来证明产品缺陷。最小修复为 put／get 首先校验键，再取 client／创建桶／读取；没有增加重试或放宽检查。

`s3-final.log`：3 passed／1 skipped，原真实 MinIO 集成仍跳过，不能标记已通过。新测补充失败关闭及资源释放，但不证明真实 S3 认证、序列化或网络兼容。

### MySQL 迁移测试陈旧断言

源码核对发现 `test_mysql_concurrent_migrations_on_empty_db` 仍断言迁移 head 为 0010，而当前 head 和其余本机迁移检查为 0011。本轮严格更新期望到 **0011**，仍断言唯一精确版本；不改 skip、锁超时、迁移执行或原库。`migration-local.log`：临时 SQLite 迁移与合成演练 6 passed／1 skipped；仅说明本机迁移链通过，不能当作 MySQL GET_LOCK 或并发迁移测试通过。

### 原沙箱跳过项的定向补验

实际首轮 XML 显示 `test_s9c_sandbox.py` 既有四项真实临时容器用例均通过，而非因镜像缺失跳过：现有 Docker 与缓存固定 digest 镜像已可用。无需拉取、升级、启服务或新增持久资源，因此在本轮隔离验证范围内只选择 `evals/security/test_s9_sandbox.py::test_read_only_sandbox_has_no_network`，单进程设置其原有 `S9_SECURITY_STACK=1` 准入，原测试 **1 passed／1.51秒**。

保留 network none、只读根文件系统、tmpfs 和原 TCP／DNS 阻断断言；不连接业务服务，不启用同开关控制的另14项全栈安全用例。原 skip 条件未改；默认全仓仍不设置该开关，仍计34跳过，只将此一项标为“默认跳过、定向已补验”。默认四项与定向一项均仅执行合成隔离脚本，不代表真实节点或业务工具运行证明。

## 必须确认的执行边界

- 独立 MySQL／Redis 集成：须确认专用实例、随机测试库／Redis 逻辑库、安全访问配置和清理授权；原夹具会建库、drop 表／库或 flushdb，不可指向现有 ai_platform 或共享 Redis。真实备份和原库迁移仍暂停，不是本机替身测试前置。
- 真实 MinIO／Elasticsearch：须确认独立测试桶／索引、访问配置和删除边界；已有本机服务不等于获准向它写入。当前不创建资源或借用生产／现有业务凭据。
- Docker／Linux：本轮已使用现有缓存完成单个沙箱补验；若需下载镜像、启新服务／新增持久资源或新的 Linux 环境，必须先确认。Linux RLIMIT 原条件不改，不能拿 macOS 或本机 Docker 客户端当作该 Linux测试已通过。
- 全栈 S8／S9：含 IdP 取票、包上传／评测／审批／吊销、工具调用和可能的观测写入；当前授权不能开启整组。可保留原离线替身覆盖，但真实链路另行确认服务／账号／数据和写入范围。
- 真实模型／FastEmbed：需确认已有离线模型缓存／依赖或真实模型端点、凭据、费用与观测出口。无授权不下载模型、不安装依赖、不调用真实 LLM 或上传 Trace。

FastEmbed 只读前检发现包已安装，默认模型为 BAAI/bge-small-zh-v1.5，但未验证完整缓存；现有加载器未显式设置 local_files_only，不能据包存在推断首次加载不联网。未构造模型／执行下载，事实摘要见 `fastembed-preflight.json`。核对指定缓存完整性仍可作为后续只读项，实际下载／新增依赖或外部模型调用须先确认。

门禁项本轮不执行，不因列出门禁而阻止已获授权的纯离线补验。北极星保持待定义；不以减少 skip 数作为验收目标。
