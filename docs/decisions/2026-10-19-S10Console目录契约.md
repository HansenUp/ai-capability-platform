# S10.6 Console 目录元数据安全契约

## 授权与范围

用户确认目录仅管理 Console IdP 映射和展示元数据，并重新授权北京时间 2026-10-19 19:23:43 至 2026-10-20 00:23:43 自动本机开发与回归。遇必须人工确认事项或到期立即暂停，不自动延长。此记录不授权提交、推送、合并、部署或生产操作；D47 继续延期。

目录不是身份或权限事实源。不创建／停用真实账号、租户，不管理密码，不修改 IdP／Runtime 角色、Agent 分配、JWT、节点路由或在途 Run。既有身份头仍只是开发方式，不以本轮目录验证宣称生产 Console 鉴权完成。

## 数据与接口

- Console Alembic `0006` 新增 `t_console_directory_tenant` 和 `t_console_directory_user`；不回填或推断真实 IdP 账号、不改变旧表和历史 Agent 分配。当前租户没有元数据时返回 `metadata=null`，不代表身份租户不存在或停用。
- `GET／PUT /directory/tenant` 只查询／整表替换当前租户的显示名称和说明。首次保存仅创建展示记录，不创建身份租户，不提供跨租户创建或全局租户枚举。
- `GET /directory/users` 按 ID 升序 keyset 分页，`limit=1..1000`、`after_id>=0`；返回 `items` 和 `next_after_id`。分页是请求时观察，不承诺并发新增／删除下的快照一致性。
- `POST /directory/users` 登记外部 issuer、subject、显示名称和说明；同租户 `(issuer, subject)` 唯一，重复 409。大小写敏感，MySQL 使用 `utf8mb4_bin`，不将 `Alice` 和 `alice` 当作同一外部主体。issuer 为不透明外部标识，不拉取、探测 URL，不把记录视作已验证身份。
- `PUT /directory/users/{id}` 只替换显示名称／说明；issuer、subject、tenant、role、enabled 等字段不能写入更新或扩展权限。更换外部身份必须明确删除／新增展示映射，仍不撤权。
- `DELETE /directory/users/{id}` 仅删除该目录记录，返回 204；不存在 404，不级联删除 UserAgent 或真实账号。删除不会阻止原主体继续按已有授权调用平台，不能用作离职撤权入口。
- 所有目录读取／写入均要求 TENANT_ADMIN 及以上，只取 Operator 的当前租户；平台管理员也不通过查询参数越租户。跨租户记录读写按不存在处理。USER／ADMIN 为 403。
- 输入为严格类型，拒绝额外字段、空名称、超长值、首尾空白及 Unicode 控制／不可显示字符；外部身份不允许空白。说明允许空字符串。目录专用路由将输入校验错误转换为不回显原始输入的 422，避免 IdP 信息反射和非法 Unicode 导致错误响应编码失败，不改变其他接口错误契约。前端使用 Vue 文本渲染，不执行内容或 HTML。
- 变更与审计同事务提交，审计动作 `directory.tenant.update`、`directory.user.create/update/delete`；只记录对象 ID 和作用域，不复制完整展示信息／外部身份至审计详情。失败无成功审计；删除记录 `authorization_changed=false`。MySQL 行锁串行单记录修改／删除，元数据更新采用最后成功写入值，不承诺编辑版本冲突检测。

## 页面与验证边界

`/manage/directory` 提供当前租户元数据保存、用户映射新增、展示编辑、分页、刷新及删除。编辑身份字段不可变；删除前页面内二次确认，明确不撤权。开发身份须显式点击应用，切换时清空旧租户列表、表单及确认框；请求期间禁重复操作，错误展示实际 HTTP 状态。历史请求的页面写回按身份代次隔离。

验证只使用临时 SQLite、已有本机 MySQL 隔离测试库和回环服务；真实浏览器的 IdP URL／主体／显示信息均为虚构测试数据。不得将页面通过等同外部身份真实性、生产隔离、外部渗透或签字。本轮不新增 IdP 管理凭据或生产服务。

## 仍未覆盖

真实租户／账号生命周期、IdP 映射可信性核验、撤权令牌生命周期、未知写对账与 Run 终止策略均不在本次授权内。Runtime 执行成功率、延迟、Token／成本等仍未在 Console 采集；现有控制面指标明确 `runtime_execution.available=false`，不得冒充零值或 S10 完整出口。S10.7 生产部署和 S9 外部出口待办保持不变，未扩展 S11。
