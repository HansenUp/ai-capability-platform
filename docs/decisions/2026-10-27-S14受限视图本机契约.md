# S14 受限视图本机契约（已按用户授权确认）

本契约仅适用于本机隔离内核与合成测试。现有策略服务 `read_data` 没有 permit，本轮不把测试注册表当作正式授权，不提供 HTTP 入口，也不接入网关、真实数据或生产。正式身份验签、策略授权、注册清单审批发布和撤权一致性仍需另行确定并验收。

- 查询只接受注册的视图 ID、明确版本、投影列、等值条件和显式限行；请求不可传 SQL、表名、表达式、连接、排序或聚合。只允许 SQLite 真实 VIEW，底层映射来自受控测试配置。
- 身份由测试宿主注入租户、主体和角色。规则精确绑定租户、视图、版本，主体或角色须命中显式允许项；无管理员通配。未知、冲突、缺失均拒绝。注册配置不可从查询参数生成，真实可信身份边界尚未接入。
- 每个请求强制以参数化条件约束视图内租户列，租户值必须为文本且按二进制精确比较，不能继承 NOCASE 或数值强制转换；投影和过滤均需已批准列。固定遮盖列在数据库投影阶段替换常量，不读出原值，也不允许作为过滤列。条件值只允许字符串、整数或 null；null 使用 IS NULL。所有标识符仅允许受控 ASCII 标识符并加引号。
- 显式 limit 为 1～100 的整数，读取最多 limit+1 行以判断截断；没有排序或分页保证，不把截断作为全量结果。数据库只读连接，禁止扩展加载和写 SQL；错误向调用者返回固定消息，不暴露 SQL 或数据库正文。
- 单次操作使用只读连接和一个读取事务；不承诺跨服务快照、撤权即时性或数据版本历史。本轮不提供 `data.query` 网络工具、下载链接、对象存储、实时注册变更或生产服务。
- 受控注册者必须保证视图中的租户列真实对应源行。仅核验视图与列存在不能证明复杂视图的来源或租户血缘，实际视图审核与注册发布必须在真实接入时单独设计和验收。
- 回归使用新建可销毁临时 SQLite、两租户合成数据及测试身份；覆盖拒绝、租户／主体／列隔离、视图类型与版本、恶意参数、遮盖、截断、只读和受控错误。不得以此宣称正式安全或 S14 完整出口通过。
