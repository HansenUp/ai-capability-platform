## 2. 联调与评审发现

- spike：goose 全新目录下仍自动加载 7 个内置扩展（config 置空无效），须经 `_goose/unstable/session/extensions/*` 移除；`GOOSE_DISABLE_SESSION_NAMING` 须为 `true`；dsh 的 ACP `agentInfo.version` 为 0.0.1，不能作为发布版本。
- 竞态：agent 在流式应答的 finish_reason 处即发权限请求，早于 shim 读完用量块，误判隔离违规——认领前等待进行中的模型流结束。
- uvloop 的 subprocess_exec 不支持 `process_group`，改 `start_new_session`。
- 独立评审必须修 3 项均已修复：① 数据面授权按工具名全局查能力、不校验目标 server（已复现跨 server 越权）；② 内联图片拦截为黑名单可绕过；③ harness_version 冻结为 "0"。建议修一并处理：密钥旁路暴露、shim 先转发后校验、强制回收残留、`/authz/mcp-check` 无鉴权与 MCP 方法未收口、池竞态与 resume 无超时、dsh 遥测开关、并发模型请求、真实探针存档。
- POC 期间 Docker VM（7.6 GiB）内存不足导致 Langfuse 组件被 OOM 杀掉，已恢复；POC 期间曾误拉一个未经批准的镜像（alpine:3），已删除。
