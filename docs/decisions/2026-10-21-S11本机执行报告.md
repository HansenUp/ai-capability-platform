- 未设置 tools 与显式 `[]` 分开处理；JSON 非对象或无效时禁用结构化编辑并阻断保存，不自动修复／丢弃原文。不兼容 Skill 配置保留高级 JSON 编辑入口。

### S11.2 Run 只读调试

- 新增 `/manage/runs`：按 Agent 筛选、游标加载下一页、指定 Run、按 seq 排序的事件时间线、增量去重与重新完整读取。
- 使用 `call_id` 关联工具名称、闸口 decision/reason 与执行结果；原始 payload 默认折叠、Vue 文本转义，不提供审批／续跑／取消等写操作。
- 浏览器直接请求既有 `/v1/runs`、detail、events、stream，不新增 Console 特权服务账号代理，不修改 Runtime 权限或公开 API。
- 用户 Bearer 仅保存在页面内存；开发请求头入口仅 Vite DEV 可见。应用新身份、离开页面及 401/403/404 均清除旧轨迹。开发 Runtime 的管理员语义不能当成生产鉴权证明。
- 终态从既有 SSE done 尾帧读取最近一次执行的 Trace ID，不把 Run ID 当 Trace；拒绝全零／非法 ID。运行中不猜测；续跑可能一 Run 多 Trace。
- 链接仅接受配置中的本机 Langfuse HTTP(S) origin 与项目 ID，不信任事件携带 URL，不接受凭据、查询串、路径前缀或外部主机。
- 手动刷新而非持续后台 SSE；审批受限视图允许序号缺口，权限变化后重新完整读取，不虚报日志丢失。
