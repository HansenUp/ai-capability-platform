# 选型确认与阶段决策纪要

本目录存放阶段性的选型确认纪要与决策纪要，记录"某一时点、由谁、确认了什么、遗留什么待办"。

与 `docs/adr/` 的分工：

| 目录 | 内容 | 特点 |
|---|---|---|
| `docs/adr/` | 架构决策记录 | 针对一项技术决策，写清背景、备选方案与后果；变更时新增 ADR 并标注废弃关系 |
| `docs/decisions/` | 选型确认与阶段决策纪要 | 针对一次确认事项（场景、负责人、接口约定、验收口径）；包含待填的责任人栏，信息到位后回填 |

约定：

- 文件名格式：`YYYY-MM-DD-主题.md`，日期为纪要形成日。
- 每份纪要包含：结论、范围、约定事项、待填项（负责人、签字、日期）、关联的计划条目与 ADR。
- 责任人未到位的栏位保持留空，不写占位人名；信息到位后直接回填并在文末"变更记录"追加一行。
- 纪要不修改 `docs/plan/` 下的计划文件；若纪要内容要求调整计划任务定义，走计划变更流程。
