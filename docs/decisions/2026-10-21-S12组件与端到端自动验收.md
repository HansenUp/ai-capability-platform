# S12.4 工作台组件与端到端自动验收

## 授权与结论边界

仅本轮本机实现与隔离回归，不启用自动跟进、不部署生产、不执行真实业务写操作；未提交、建分支、推送或合并。保留全部原有未提交变更。本轮没有必须人工确认而绕过确认实施的事项。

本轮补齐使用工作台的真实 Vue 挂载组件测试，以及浏览器驱动的「创建 → 发布 → 对话 → 审批 → 输入补充 → 同 Run 完成」自动验收。没有替换产品页面、SDK 或 Runtime API；没有把 helper 测试冒充组件测试，也没有把拦截 HTTP 的组件测试冒充真实后端端到端测试。

S12 整体仍未完整出口：运营反馈／北极星口径、真实节点操作、统一登录、工作台多轮／实时流／附件及全站组件覆盖不在本轮验收内。S9 外部验收继续待办，D47／Helm／Argo CD／S10.7 延期不变。

## 实现与隔离契约

- `apps/console-web/tests/browser/workbench.html` 直接挂载真实 `Chat.vue` 与真实 SDK；仅 RouterLink 由最小组件替身代替，Runtime 请求由 Playwright 路由替身控制。每项测试使用独立浏览器 Context。
- `component.test.mjs` 新增 5 项：身份应用清空令牌／用户鉴权头／403 清空卡片；审批预览不写入、切换 Run 撤销确认；JSON 解析与服务端 400、同 Run 完成；网络结果未知锁定且身份切换不解锁；凭据仅走身份头、reconcile 只读。断言无令牌持久化、无错误响应体泄漏。
- `e2e.test.mjs` 使用真实 Console 页面、Console API、Runtime API 和独立临时 SQLite 数据库；浏览器不拦截业务接口。Console 草稿与发布请求确实同步到 Runtime，而非伪造已发布响应。
- 复用 `verify_s12_workbench.py` 的离线签名测试 IdP、策略替身、Mock Harness 和 `_dev_execute` 工具替身；增加仅夹具使用的确定性审批后输入场景。所有写工具只返回 `simulation=true, external_effect=false`，不调用工单、邮件、模型、外部 MCP 或节点。
- Runtime 强制 JWT 验签，Alice 为发起人，Bob 为另一测试用户，foreign 为另一租户。Console 使用显式开发态身份和临时签名服务令牌，不冒充生产身份体系或真实 OIDC Client Credentials 换票验收。
- 发布复用现有 `CONSOLE_EVAL_GATE=flag`，必须在页面显式勾选开发确认并二次确认。此处只验收发布链路，不宣称真实 Langfuse 评测通过。
- 仅随机 `127.0.0.1` 端口和新无头浏览器临时 Profile；不接管用户已有浏览器或服务。测试令牌文件为 0600，结束删除；Console／Runtime／Vite／浏览器均停止，不记录 trace、视频或鉴权头。
- 新增 `make verify-s12-browser`：先构建 SDK，再自行编排夹具、Vite 和 Node test runner。支持 SIGINT／SIGTERM 停止自有子任务并进入清理；测试失败返回非零。

## 真实端到端检查点

1. 页面新建唯一 Agent 草稿，检查 `draft`；复用发布页面、显式开发评测确认和二次确认，检查 `published`。
2. Alice 经 SDK 只创建一个 Run；读取真实 Runtime 状态进入 `auth-required`。
3. Alice 自批被拒绝 403，旧审批卡清空；切换 Bob 后重新读取同一 Run，确认批准。
4. 真实自动续跑同一 Run 到 `input-required`；Bob 回答被拒绝 403。
5. 切回 Alice，非法 schema 回答被拒绝 400；合法合成回答后同一 Run 到 `completed`，页面显示最终模型文本。
6. 核对持久化事件：一次 `run.created`、一次 Bob `tool.approved`、一次合成 `tool.executed`、一次 `input.provided`，工具结果无外部效果；浏览器没有调用 `/resume` 或重复创建 Run。
7. 切换另一租户访问该 Run 返回 404，旧 Run 视图清空。截图在令牌输入已清空、终态可见时生成；结果 JSON 只保留合成 ID 与断言摘要。

状态等待只轮询只读 GET，不重试写请求。定位等待上限 5 秒，状态等待上限 10 秒，单测试上限 30 秒；未通过放宽阈值或断言绕过问题。

## 调试与修正

首次组合夹具暴露同一进程两个线程同时执行 Alembic 迁移的全局上下文冲突：改为等待 Runtime 健康后再启动 Console，仍完整运行双方真实迁移，不跳过迁移。随后端到端发现合成 Harness 只有 Text／Done 而缺少 Usage，未产生持久化 `model.response`：按既有 Mock Harness 契约补发合成 Usage。均为新增测试夹具修正；未修改 Runtime 生产语义，也未放宽最终模型文本断言。
