# S12.3 写锁、只读跟随与恢复跨功能验收

## 范围和契约

仅本轮临时库、签名测试身份、Mock Harness／无外部效果工具和 Langfuse 替身，不做真实备份／原库迁移、业务工具／评分／Trace 写入或生产部署，不启用自动跟进。测试允许本机生成 Trace ID，两个 OTLP 导出地址保持为空，不导出真实 Trace。

读取不执行或确认写操作；PREPARED 及已终结但未本人收口的账本均冻结同主体新写。SSE EOF、done、Run completed、停止读取、空列表、换令牌或卸载都不是解锁证据。不同主体独立验权和读取其账本：不能把 Alice 的锁当成 Bob 的锁，也不能由 Bob 清 Alice 的锁。身份更新须清旧事件／游标，原操作者换令牌仍恢复服务端锁；卸载释放迟到响应，不继续读写。

新增三项 DOM 用例挂载真实 Chat／SDK，受控 SSE 替身可忽略 abort、延迟返回头、主动断连。它们是组合状态测试，不冒充真实 Runtime 的端到端来源；增强的创建 E2E 则使用实际回环 Console／Runtime、临时 SQLite、验签测试 JWT 和工具替身。

本轮核对未证实需改变业务实现的缺陷，因此只补组合覆盖与既有 E2E 检查，不为新增测试重写 SDK／Runtime 状态机，不扩展多轮、Token 流、SSE 自动重连、ACK 或解锁策略。若验证暴露失败，保留原始证据并按原因处理，不放宽断言或超时。

## 验证结果

证据目录 `docs/evidence/s12/2026-10-23-workbench-cross/`。

- SDK 定向 workbench／ledger／SSE／trusted-feedback helper：36/36。
- Runtime 各动作账本／工作台／Run API 与 SSE 专项：67 passed／1 个既有警告，25.32 秒。
- 全部前端 helper：77/77；Ruff 检查及格式 382 文件、mypy 109 文件、OpenAPI 一致性通过；SDK／Console／Portal 类型检查及本机构建通过。
- 首轮浏览器 `browser.log`：79/79，152593.95ms，包含新增三组组合测试；临时进程／测试令牌清理通过。增强创建 E2E 与测试夹具在该轮期间完成补充，因此最终冻结测试版本还要完整复验，不以中间轮代替冻结结果。
- 全仓 `full-python.log`：**1508 passed／34 skipped／2 warnings，446.96 秒**。没有新增 Python 用例，因此数量与上一轮相同，但此处是本轮实际执行结果；34 个跳过未计通过，既有 Starlette／测试短 HMAC 告警未压制。
- 冻结版本最终浏览器 `browser-final.log`：**79/79，141127.46ms**；新增三项 DOM 和增强的实际 Runtime 创建／SSE 对照均通过。两轮浏览器均报告临时 Console／Runtime／浏览器停止及测试令牌文件删除。不提高 5000ms 页面断言或 30000ms 单测试／文件上限，不跳过失败用例。

新增 DOM 以公共锁状态机的 PREPARED／COMMITTED 未收口及 credential 样例做组合，实际 E2E 补 create 的权威回执对照；其他动作沿用原有定向及完整回归。不是声称穷尽所有动作、网络与租户组合，也未扩展连接中令牌失效后的服务端重验语义。本轮普通技术选择为复用既有夹具和接口、仅补测试，不涉及需先确认的业务取舍。

本轮无回归失败，未修改业务源码、依赖、数据库或真实环境配置；新增三项 DOM、增强一项既有 E2E。`result.json` 保存计数、隔离边界与相关源码散列；`git diff --check` 通过，自动跟进核实 PAUSED。可以声明本轮约定组合覆盖完成，不声明全部 S12.3／生产出口完成。
