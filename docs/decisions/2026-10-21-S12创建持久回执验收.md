## 关键契约与实现

- 创建前无 Run ID：客户端只传 attempt UUID、Agent ID 和消息。服务端校验实际验签主体及当前可见发布版本，锁定主体并提交 PREPARED；仅预留随机 Run 标识，不写 Run／输入／凭据、不入队。UI 明确“登记新 Run（尚未创建）”，预留 Run 404 不作为解锁依据。
- 快照及原文：账本只存 Agent 版本／模型／选版元数据、域隔离 HMAC 内容及快照绑定，不另存消息或完整配置。消息只在原 RunInput 执行存储中按既有规则落库。登记后页面重载不恢复原文，原操作者需重新输入同一纯文本并显式执行。
- execute 重校验主体、版本／指纹、原值及当前可见 Agent 选择和快照。换值／漏值拒绝并保留 PREPARED；版本撤回、选版或快照变化失败关闭，不悄悄改版。绑定密钥变化不重新散列旧记录或自动解锁。
- 从 runner.create_run 抽取不自行 commit 的 persist_run；旧包装保持原签名、字段、租约、提交和入队行为。新执行在同一事务写入预留 Run、原 RunInput、加密凭据、唯一带 attempt／消息及快照绑定的 run.created 和 COMMITTED。部分写后未分类异常整体回滚；有确定无创建效果的预期拒绝才记 REJECTED_NO_EFFECT。
- 创建 request_seq=0 专指尚无创建事件，终结证据必须为该 Run 的 run.created seq=1。COMMITTED 仅证明创建受理，不代表模型／工具或 Run 执行成功。提交后复用既有队列及 reaper 兜底；同 attempt 已决重放不再创建、重复事件或入队。
- ACK 不带消息，核对原主体、attempt、创建动作、范围、版本／指纹、精确事件中的主体／Agent 版本／模型及内容／快照绑定，然后由本人显式确认。取消收口不写；他人／跨租户不可读或确认。Run 终态、SSE done、TTL、空列表、404、换令牌或清空浏览器均不自动收口。

迁移 0010 仅增加可空创建元数据，临时库验证旧 answer 的内容绑定、活动指针、升级／降级／重升级及 ORM 一致性；S7 head 断言精确更新到 0010。未升级现有业务库或生产库。SDK 严格校验新动作、预留序号、Agent 快照和唯一创建事件，并保护不可变字段；Chat 先验签身份及主体账本再允许登记，丢登记响应时可从主体账本恢复，不依赖先取得 Run ID。

旧 API 保留兼容：活动锁阻止其新 POST 准入，不追溯已经准入的旧请求。新增确定性屏障用例证明：旧创建已通过依赖、暂停在 Agent 加载时，新主体锁可登记；释放后旧请求仍正常创建，但不能冒充新 attempt 的预留 Run 或终结证据。范围是明确的准入边界，不是全部旧 API 已改为同事务回执协议。

## 失败与自主选择

首次新增测试误引用 runtime.loop.credentials，收集阶段报 ImportError；核对原仓库夹具后改为真实 runtime.credentials、test_s7_run_api 与 EventLog reaper 查询位置，原测试断言未放宽。初次 Ruff 报导入顺序，补迁移用例后还发现 SQL 字面量过长；按原格式及拆分相邻 SQL 字面量修正，不修改行长规则、超时、重试或跳过。首轮格式补丁生成失败时没有形成可用 patch，apply_patch 明确拒绝，修正后才应用。失败日志与真实测试通过记录分别保存，不把收集失败计为回归通过。

自主执行的普通技术选择：只接入既有单条文本；独立 create-attempts 请求体不要求 Run ID；预留标识与请求序号 0 明确未创建语义；复用既有 HMAC、选版和原事务字段；快照变化失败关闭；调用方持有共享事务，复用既有队列。不新增业务绕过或付费／持久服务。
