# 任务结果与同 Run 导航验收

本轮由单 agent 执行。保留 B2 SDK 及既有 B3 修改，不提交、不推送；只使用临时 SQLite、签名测试身份和模型/工具替身。未连接真实业务、原库或生产。

## 实现

- Console Chat 与 Runs 共用任务结果卡：分别展示 Run 状态、当前可见 tool.result 成功/失败或拒绝/未知事件数、助手文本是否存在。不把 completed 或助手文本认定为有效业务摘要；缺失证据不推断成功，不解除未决写锁。
- Chat→Runs→Chat 传递经过格式限制的 Run ID，链接不是权限证明。新页面/重载仍须应用身份、显式定位并只读读取；没有自动重发或持久保存令牌。
- Runs 应用身份时清空旧 Run ID；原有身份切换与旧请求隔离机制保留。轨迹增加请求、授权、开始执行、工具结果、助手输出阶段标签，原始事件名/序号和正文仍可查看。
- 不改 Runtime、SDK、权限、审批或回执契约。当前只做 Console 结果/轨迹体验增量，未宣称 Portal 新增同等结果卡。
