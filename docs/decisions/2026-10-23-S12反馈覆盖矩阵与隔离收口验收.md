# S12.1 测试覆盖矩阵与隔离收口验收

## 授权及隔离边界

仅本轮临时库、签名测试身份和 Langfuse 替身，不做真实备份／原库迁移、不写真实评分或 Trace、不部署、不启用自动跟进。全仓测试移除外部 Runtime／Console 数据库选择，清空 Redis 和 OTLP 出口；Runtime 测试夹具使用独立临时 SQLite、Mock Harness 和策略／认证替身。浏览器夹具启动回环 Runtime／Console、临时 SQLite、合成工具，生成本机 Trace ID 但清空 OTLP 导出地址，Observe 的外部交付使用替身。临时 Mock Worker 是隔离测试的一部分，不是启用现有真实 Worker。

## 执行结果与失败证据

结果日志位于 `docs/evidence/s12/2026-10-23-local-closure/`。

- 反馈专项：87 passed／1 个既有 Starlette 警告，7.81 秒。
- Console helper：75/75。
- Ruff 检查及格式：382 文件；mypy：109 文件；OpenAPI 一致性通过。
- 浏览器首轮未进入组件断言：项目没有可解析的 `playwright` 包，17 个测试文件加载失败，日志 `browser.log` 原样保留；临时服务与测试令牌已清理。通过既有 `PLAYWRIGHT_MODULE` 扩展点复用桌面捆绑 Playwright 和已有 Chrome，不安装或升级依赖，不修改测试时间限制。
- SDK／Console／Portal 类型与构建全部通过，完整日志 `frontend.log`；Console helper 为 `helpers.log`。
- 全仓首轮 `full-python.log`：1500 passed／6 failed／34 skipped／2 warnings，436.63 秒。六项失败均为内存 exporter 找不到预期 span，原因是本轮命令设置 `OTEL_SDK_DISABLED=true`，并非反馈业务失败。修正验证环境为 `false`，保留两个 OTLP 出口为空；源码确认无端点时不安装网络 exporter，不增加重试或放宽断言。完整复验 `full-python-tracing.log`：**1506 passed／34 skipped／2 warnings，470.90 秒**。未压制既有 Starlette／合成短 HMAC 测试警告，跳过不计通过；此结果包含新增四例及当前既有测试，不沿用旧报告总数。
- 捆绑依赖浏览器轮 `browser-bundled.log` 出现 AgentConfig 文件和可信反馈 E2E 两处 30000ms 超时，失败证据保留。该轮同时运行全仓 Python；不能仅凭并发就断言全部根因已查明。全仓结束后单独按原 30000ms 文件／测试上限、5000ms 页面断言重跑完整套件，`browser-serial.log`：**75/75 通过，138448.17ms**；原失败场景分别完成，可信反馈 E2E 为 7444.42ms。没有跳过或删除失败用例，没有改超时；当前串行验证通过，不宣称所有调度抖动已被根治。
