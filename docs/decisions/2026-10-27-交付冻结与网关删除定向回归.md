## Runtime 测试隔离根因及最终复验

首轮和两次诊断中，pytest 原断言 59 passed，但安全审计拒绝 10 次访问 `127.0.0.1:1`，runner 均退出 1。隔离夹具显式将 Gateway URL 配为该端口；`runtime.assemble.assembler.discover_core_tools` 在组装时读取 `/capabilities`，网关不可达时捕获 `httpx.HTTPError` 并按既有逻辑回退本地注册表。

在测试 runner 中通过已有 `gateway_client.set_transport_for_tests` 接入 MockTransport，仅允许 `GET http://127.0.0.1:1/capabilities` 并抛 `httpx.ConnectError`，其他请求立即报错；保留原测试断言和网络禁令。最终 `runtime-sdk-final.log`：59 passed、1 warning，pytest 与 runner 退出 0，`blocked_actions=[]`，10 次能力发现均被该纯替身处理，临时根已清理。此结果验证网关不可达回退条件下的工作台集成，不验证真实网关；未改 Runtime 产品代码、扩大超时或允许连接。测试 runner 的 Ruff 检查通过。选定 537 项源码指纹复验一致。
