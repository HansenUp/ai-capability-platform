## 2. 联调发现

- Keycloak 的会话 Cookie 带 Secure：浏览器把 localhost 视为安全上下文照常发送，脚本里的 httpx 在 http 下不发，登录表单返回 `cookie_not_found`。验证脚本显式带 Cookie；浏览器实测登录不受影响。
- 缺少 code_verifier 的换取请求会被 Keycloak 拒绝，并使该授权码作废（PKCE 生效）。

## 3. 验证

- `make verify-s3`：经 Console 发布 v1 全量、v2 灰度 10%，200 个主体中 15 个进入 v2；放量到 50% 后 88 个；一键回滚后 201 个主体（含白名单）全部回到 v1。PKCE 登录 alice、真实模型对话、点踩并修正后，Langfuse 对应 Trace 上出现 user_feedback = -1。
- 浏览器实测（本机门户 5173）：未登录访问跳转 Keycloak，登录后回到 Agent 列表、对话、点击点踩，Langfuse 收到评分，Runtime 审计记录该次反馈请求。
- 本阶段未做独立代码评审（会话费用较高，留待下次评审一并进行，见遗留 1）。
