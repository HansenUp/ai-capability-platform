## 推荐迁移与回滚契约（待确认，不执行）

1. 接入负责人先以获授权的配置清单、服务归属和脱敏访问统计核对旧路径调用方、版本、租户、方法及回滚窗口；本轮没有这些资料。确认新入口、目标 Server 注册映射、支持的方法和消费者变更。不得把 `/mcp/servers` 管理接口改写成数据面。
2. 分别验收平台 `/invoke` 和第三方数据面：用户 OBO 的 issuer、audience、租户／主体绑定、真实签名 act 的生成／受众／令牌哈希绑定、服务间回调认证和撤权；不同信任边界不得由客户端自报头代替。
3. 第三方数据面只对已验证身份的 tool call 使用回调；回调 403、503、超时、不可达或非预期响应应失败关闭并不转发。`require_approval` 在当前回调返回 200，必须由 Runtime 的审批契约先行约束；本轮替身自行阻挡审批不能证明真实 agentgateway／Runtime 已联动。对非 tools/call 的 resources、prompts、notifications 和流式语义需分别明确策略。
4. 切换前用批准的非生产环境测试功能、身份、故障、延迟与回滚；明确渐进路由、观测、回滚责任人和不允许重发写操作的原则。是否提供旧路径兼容层、消费者迁移时限及回滚方案须负责人确认，不自行恢复旧代理或建立不安全双路径。
5. 部署、变更真实配置、密钥及数据流需单独授权；此处只给候选方案。

## 纯替身验证

新增 `services/capability-gateway/tests/test_synthetic_dataplane_chain.py`：测试内独立假数据面使用测试 IdP ES256 对令牌验签，提取主体／租户，进程内调用实际 `/authz/mcp-check`，并只将 allow 后的测试令牌及主体交给模拟上游。覆盖过期、错受众、伪造签名、空租户、错误回调 token、模拟回调不可达、策略不可达、deny 和 require_approval；均断言不转发。测试假数据面主动拒绝 require_approval，是测试安全假设而非 agentgateway 真实能力；假数据面清理伪造头、使用固定可信 agent 也只能证明测试构造，不能证明 agentgateway 配置会安全剥离头或生成签名 act。

相同隔离组同时执行原 `test_dataplane_authz`、`test_gateway`、`test_gateway_invoke`、`test_connectors` 和网关 act 签名字段专项。原 `/invoke` OBO／act 测试是单独的实际代码路径证据，不是 agentgateway 真实代理证据。命令 `.venv/bin/python docs/evidence/baseline/2026-10-27-dataplane-migration/verify_chain.py chain`：**52 passed、1 warning、pytest／runner 退出 0**；阻断动作 0、SQLite 连接 0，测试临时根已清理。证据见 `chain-verified.log`，选定文件散列 `review-hashes.json` 为测试后的记录，并非全仓冻结。新增测试 Ruff 检查通过。未跑浏览器或全仓。

## 剩余关键风险和确认资料

- 真实调用者／旧路径退役时间、是否需要兼容层与回滚责任未知；需网关和业务负责人提供经授权的消费者清单与期望切换顺序。
- POC `x-ai-act` 头部整形不等于网关签名的 `X-AI-Act-Assertion`；MCP 生产认证要求验签、受众和 OBO 绑定。正式数据面如何产生、保护并验证该断言仍须确定并做真实隔离验收。不能把 POC 中客户端可控头或开发模式当正式委托证明。
- 实际 agentgateway 对 JWT、伪造头剥离、回调不可达、审批、方法白名单及流式的行为，本轮没有执行；旧路径若仍有消费者，删除可能造成 404。
- 外部真实服务、凭据、网络、容器／部署和上线另需授权。测试身份与回调测试密钥仅为合成数据，不包含真实秘密；未做任何真实业务写或生产部署。
