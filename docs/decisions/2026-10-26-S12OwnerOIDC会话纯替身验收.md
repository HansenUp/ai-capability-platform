## 1. 实现与默认关闭边界

测试页面`apps/console-web/tests/browser/owner-session.html`以Vue真实挂载OwnerOperations，通过内存token端点替身和WebCrypto临时RSA签名／验签模拟IdP。公私测试材料在新浏览器上下文内生成，不读取磁盘或真实密钥；没有真实JWT／JWKS、账号、scope或服务凭据变更。

## 2. 已实现契约

| 项目 | 规则 |
| --- | --- |
| 固定profile | HTTPS issuer／同origin授权端点，精确redirect URI；无userinfo、query、fragment或空白；只允许HTTPS或隔离127.0.0.1 HTTP回调 |
| Scope | 显式独立测试ownerScope＋openid；拒绝把act、ai-runtime、offline_access或openid本身当Owner scope。测试名synthetic-owner-read不是正式IdP声明，不证明实际mint受众已隔离 |
| PKCE | crypto.getRandomValues分别生成32字节state、nonce和verifier；SHA-256 S256 challenge；授权码流程，固定client／redirect，无implicit、client secret或password grant |
| 登录事务 | 最长300秒，恰好到期拒绝；仅内存，单事务。发起新登录立即撤下旧Bearer、身份与指标；callback在任何异步交换前先消费事务，失败不重用code、不重试 |
| Callback | 精确origin／path，必需且单值code／state／iss，拒绝其他字段、hash、userinfo与超长输入；state与issuer精确匹配；错误／取消消费事务并保持未登录 |
| ID身份 | 必须先调用受控验签能力，再核对签名后的iss、单aud、azp、nonce、非空sub／tenant及整数exp／iat／nbf；零时钟宽限，寿命不超过600秒。替身实际使用RS256签名验证，并测试篡改签名 |
| Access响应 | 仅Bearer、非空有限长度access／ID token、整数expires_in在1～600秒；拒绝refresh token等未支持字段。会话到期取expires_in与ID exp较早值，计时器与读取／响应接纳前双重检查 |
| 存储／恢复 | access、ID处理和PKCE事务均不写localStorage／sessionStorage／cookie／URL；重载不恢复会话或未决事务，必须重新认证；无自动refresh、静默SSO或跨标签共享 |
| 并发／身份 | 登录代次贯穿digest、exchange和ID验签；旧登录成功／失败不能覆盖新主体或租户。退出／卸载销毁事务、Bearer、计时器与监听；迟到回调不能复活 |
| Owner数据 | 连接变化立即清空并abort；即使忽略abort，旧响应代次不能回写。新响应租户还须与会话核验tenant一致；401／403／404或租户冲突清空会话，不显示上游私密正文 |

ID令牌只用于本机登录身份展示与隔离，不代替Owner API的access用途证明。后端仍验签access token、单Owner aud、at+jwt／token_use=access、真实主体绑定及当前UserAgent分配；本轮没有把浏览器展示身份升级成X-Console-*授权头或分配权威。替身返回opaque合成access标记，Owner摘要也由纯内存替身返回，不冒充本轮已做真实签名后端端到端联调。

本轮模拟为**非导航式内存授权交接**：begin返回固定授权URL给显式替身，callback接收测试URL但不导航浏览器。没有实现真实登录重定向、popup／postMessage、callback路由或BFF；实际整页导航会丢失本轮内存事务，这是拒绝恢复而不是完整导航式SSO。未擅自启用sessionStorage的PKCE例外；未来若需真实导航承载方式，先确认安全方案及回调清理，再实施。
