# S12.1 Owner JWKS纯替身轮换验收

日期：2026-10-26。范围：承接已冻结参数，仅使用临时SQLite、签名测试身份及内存HTTP替身，补齐Owner JWKS缓存与验签路径。本轮不读取真实密钥、不连接真实服务／原库、不改IdP、不写真实评分／Trace、不部署或恢复自动跟进；北极星仍待定义。

## 1. 实现与冻结参数

新增`services/console-api/src/console_api/owner_jwks.py`的`IsolatedJwks`。构造必须显式注入`httpx.MockTransport`，不提供真实transport默认值，不从.env／token／discovery加载地址或密钥；固定HTTPS URI，拒绝凭据、query、fragment、空白及控制字符，最长2048字符。仅GET、trust_env=false、禁止重定向、无用户Bearer转发。

| 参数 | 实际约束 |
| --- | --- |
| 请求截止 | HTTPX各阶段5秒，加asyncio整体5秒截止；无重试 |
| 响应 | 解码后最多65536字节，超限拒绝；严格JSON重复字段检查，不返回上游正文 |
| 缓存 | 成功完整验证后有效300秒，恰好到期不可用；不使用过期缓存 |
| 刷新 | 每实例最多每30秒一次尝试，包括失败；未知kid只触发一次受限刷新，无后台刷新／重投 |
| 并发 | 同事件循环asyncio锁串行准入；已刷新键共享，未知kid／失败等待者受同一冷却限制，不形成刷新风暴 |
| 密钥 | 最多32个公钥、非空keyset；RSA≥2048位、固定RS256、唯一非空kid、use如有须sig、key_ops如有须verify；私钥／额外字段／任一非法键使整个新keyset拒收 |

有效期内旧键可用于已知kid，即使一次未知kid刷新故障；其原300秒到期不续期。成功刷新整体替换keyset，已删除kid不得回退旧集合。该有界旧键信任不等于即时密钥撤销。非法新keyset不部分合并，且不能使过期旧缓存复活。

`invalidate()`清空键并递增缓存代次，在途旧代次下载不能发布；保留30秒冷却，不借失效绕过限频。不同正式配置应构造独立cache并整体替换不可变profile，不能只改URI保留键。当前只在测试中显式注入，没有启动加载／真实配置入口。

## 2. Owner路径接入与配置切换

`LocalProfile`可选注入替身JWKS，且必须开启上一轮access用途契约。两个Owner GET的T1／T2均改为异步验签包装：先校验本机开关、身份头和JWT header，再按kid取公钥，最终仍执行原签名、issuer／单aud／azp／用途／期限／绑定／角色校验与UserAgent分配。

缺Bearer、非法算法、jku／jwk／x5u／crit等自报信任根不触发下载；请求只能访问固定替身地址。JWKS未知kid／不可用返回受控503，签名／用途非法401，不返回部分指标。固定公钥旧测试profile路径保留，未改管理员／Runtime／发布／节点权限。

取钥等待期间profile发生切换，旧请求403且不使用已取得公钥返回数据；T2前缓存过期且刷新失败，已读取Trace也必须丢弃。T2之后已准入响应可完成的既有边界不变。keyset变化不赋予新绑定或Agent分配。

当前缓存仅单实例／单事件循环，不是多进程共享缓存或发布协调器；进程重启重建缓存，不宣称全局限频／跨进程即时撤权。不实现真实JWKS认证配置、OIDC会话、持久发布或管理员变更接口。
