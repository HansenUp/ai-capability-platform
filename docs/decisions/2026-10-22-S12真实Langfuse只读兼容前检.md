## 已有实现要求与待核验风险

| 项目 | 仓库实现 | 真实版本所需证据（当前均未取得） |
|---|---|---|
| 评分列表 | `GET /api/public/v2/scores`，name=user_feedback、page、limit=100，上限 20 页 | 认证、路由可用性、data／meta 形状、分页字段类型、总数及稳定性；接口不存在或超限须受控不可用 |
| 单条评分 | `GET /api/public/v2/scores/{score_id}` | 成功与缺失状态、返回形状；404 不是无效果或解锁证据 |
| Trace | `GET /api/public/traces/{trace_id}` | id、sessionId、metadata 中 Run／租户／Agent／主体的实际映射、平铺与 attributes 冲突拒收 |
| 载荷在线核验 | Runtime 权威 outbox／OBSERVED 摘要与当前评分严格比较 | timestamp 格式／精度、NUMERIC 序列化（如 1 与 1.0）、metadata 保留及额外字段；均为待验证风险，不能宣称该版本已经发生转换 |
| 最新修订 | Runtime 已接受修订号，而非 Langfuse updatedAt | 最新缺失、未观测、中性或篡改不得回溯；读取失败不得给出部分正式比率 |
| 历史隔离 | 无权威协议证据的历史评分始终未验证 | metadata.verified、自报主体、关联一致、接口返回 200 均不足以升级信任 |

仅靠只读 API 和已有历史数据，最多确认读取形状及已有记录的关联；**不能证明固定 ID 写入幂等、改评不可变、乱序交付、未知结果恢复或真实 Runtime→Observe→Langfuse 来源链**。本轮不为兼容猜测修改摘要规则、时间精度、数值类型或信任判定。
