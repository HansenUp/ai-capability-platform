# ADR-0011 执行者身份与副作用可回滚

- 状态：已采纳
- 日期：2026-09-12
- 关联需求：RT-24、RT-25、CG-18
- 依据：外部设计评审第 02、06、07 条；代码核查确认为现存缺陷

## 背景

三处问题在代码中得到确认。其一，令牌交换接口的执行者标识直接取自请求体并写入委托声明，可伪造。其二，工具执行发生在追加已执行事件之前，两步之间崩溃会留下结果未知窗口，重放时幂等键查不到记录将重复执行下游写操作。其三，发布快照只锁模型别名与配置，未锁 Harness 版本、实际命中模型、能力包内容摘要、工具契约版本与检索配置，能力包重新物化会改变运行中任务的行为。

## 决策

执行者身份由平台签发。委托声明依据经过认证的调用方身份在服务端组装，请求体中的任何执行者字段一律忽略；非受信任的调用方拒绝签发。同时校验目标受众与权限缩减，下游独立验签。

副作用改为写前记录。执行前先落一条执行中事件，携带操作编号与参数哈希并提交，然后执行，然后落已执行事件。恢复时若发现执行中事件没有对应的已执行与结果事件，判定为结果未知，不得重新执行，改为迁移到需要外部输入状态并推送对账卡片，由人工确认或对账后继续。

幂等责任按风险分级。不可逆的高风险写必须由下游业务系统实现幂等，幂等记录与业务写入同事务提交，做不到则不允许上架为可自动执行的能力，只能降级为生成建议加人工执行。可逆的低风险写允许由平台侧对账。所有等级都必须有转人工兜底。操作编号在审批通过时生成并落库，重试复用同一编号。

发布快照补全为完整依赖集合，至少包含 Harness 版本、实际命中的模型标识与路由配置、提示词、能力包内容摘要、工具契约版本、检索配置与评测证据。运行中的任务锁定旧快照，普通升级只影响新任务，安全撤销独立处理可立即阻断。

## 备选方案

依赖下游幂等而不做写前记录。下游未改造完成前无保护，且无法区分未执行与结果未知，不采纳。

结果未知时自动重试。在不可逆操作上可能造成重复写入，不采纳。

## 后果

Run 事件类型增加执行中事件，状态机需允许从执行中迁移到需要外部输入。令牌交换接口的请求结构变更，生产路径在网关客户端认证实现前为失败关闭。业务系统的幂等改造成为高风险写能力的上架前置条件，需要 IT 或业务负责人确认预算与排期。发布快照新增字段需要数据库迁移。
